# SKL-AUTO-GITOPS — Automatisation NetDevOps et GitOps

## Description
Maîtrise des pipelines d'automatisation d'infrastructure as code (IaC), déploiement continu NetDevOps et contrôle des dérives via GitOps (ISO 27001 A.8.9).

## Compétences Attendues
- Conception de référentiels Single Source of Truth (Git, NetBox).
- Pipelines de validation automatisée (shadow environment, tests canary de préfixes réseau).
- Boucles de réconciliation automatique et déploiements déclaratifs.
