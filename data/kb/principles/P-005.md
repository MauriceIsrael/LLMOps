# P-005 — Shadow validation before arming

## Statement

Every rule, model or component upgrade is validated on real data before being armed: replayed history for coverage of known incidents, then live duplicated traffic in an isolated environment that can only log what it would have done.

## Why

Pre-production never reproduces the noise, the bursts and the edge cases of a real network. A rule validated only against synthetic traffic is untested where it matters.

## Implications

- An isolated environment with no production credentials and no route to production assets.
- Duplication is temporary, filtered and traced as a versioned configuration change.
- Promotion is a reviewed change against quantified exit criteria.

## How to verify

Verify the shadow environment has no credential and no network path to production; the check is repeated after every infrastructure change.
