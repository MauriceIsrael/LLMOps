# P-015 — The model stays inside the trust boundary

## Statement

Inference is served on infrastructure operated by the project. No prompt, retrieved context or generated result leaves the platform.

## Why

Tool outputs may contain configuration fragments, addresses, credentials and subscriber identifiers. Controlling what crosses a boundary is a procedural control that must be proven repeatedly; not crossing it is a structural property proven once.

## Implications

- Capacity, not confidentiality, becomes the limiting factor; latency must be measured before committing to an interactive use.
- The endpoint is a configuration value, so adding acceleration hardware later is not a redesign.
- Compatible with a fully disconnected deployment.

## How to verify

Confirm no outbound network path exists from the inference service, and that the deployment survives disconnection.
