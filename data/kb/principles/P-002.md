# P-002 — Human in the loop

## Statement

Detection is automatic, decision is human, execution is automated. No remediation action reaches production without an explicit human approval, recorded in the service management system.

## Why

The failure mode of autonomous remediation is not a wrong action; it is a wrong action taken confidently during an incident, when nobody is watching the automation because everybody is watching the outage.

## Implications

- Every remediation workflow starts with an approval node carrying full context.
- Approval can be delegated to the ITSM change process so it lands in the customer's own governance.
- Autonomy is granted later, per class of event, never as a design default (see P-004).

## How to verify

Trace any production change back to an approval record with an actor and a timestamp. A change without one is a defect.
