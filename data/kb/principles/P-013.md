# P-013 — Assistant configuration is code

## Statement

Agent definitions, system prompts and the list of tools requiring human confirmation are versioned, reviewed and promoted through the same pipeline as any other rule.

## Why

A prompt is a behavioural specification. Left outside version control it becomes an untracked change to how the system reasons, with no history and no review.

## Implications

- Prompt changes are reviewable diffs and can be validated in the shadow environment.
- The assistant inherits the governance already built for rules.

## How to verify

Trace any change of assistant behaviour to a reviewed commit.
