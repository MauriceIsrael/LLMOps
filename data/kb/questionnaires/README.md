# Questionnaires

Structured due-diligence instruments. Each question carries **why it matters**
and **what it costs if the answer is negative**, which is what turns an audit
into a reusable asset rather than a checklist.

Copy a questionnaire into `projects/<engagement>/answers/` and fill the `answer`,
`answered_on` and `source` fields there. Never fill answers in the core version:
answers are engagement facts, questions are reusable assets.

| Id | Scope |
|---|---|
| QST-core-ems | Mobile core element manager northbound capability |
| QST-service-management | ITSM, order management and inventory products |
| QST-cloud-platform | Container platform, observability and assistant |
