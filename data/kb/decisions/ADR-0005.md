# ADR-0005 — Access the mobile core exclusively through the element manager northbound interfaces

## Context

The mobile core runs on dedicated vendor-operated infrastructure with its own element manager, which maintains its own view of node configuration. Direct node access over standard protocols is technically conceivable.

## Options considered

**Direct configuration of nodes.** Uniform with the transport domain, no dependency on element manager interfaces; creates a second configuration master, triggers resynchronizations, and voids supportability.

**Element manager northbound interfaces only.** Preserves supportability and single mastership; capability depends on version and licensing, and must be audited before commitment.

## Decision

All configuration operations on the core pass through the element manager northbound interfaces. Nothing is deployed on the vendor platform.

## Consequences

Backup becomes an export, drift a comparison of exports, a fallback plan a pre-validated delta. Observability of the core is limited to what the vendor exports, and any gap must be declared. The feasibility of the whole core scope depends on an audit performed before commitment.

## Revisit when

The vendor exposes a supported model-driven interface with equivalent guarantees, or the audit shows the northbound interfaces cannot export, import or read.
