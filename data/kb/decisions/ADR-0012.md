# ADR-0012 — Shadow environment on a separate cluster

## Context

Rules must be validated against real traffic, which means the validation environment receives production data and could, if misconfigured, act on production.

## Options considered

**Namespace separation inside an existing cluster.** Cheap; isolation rests on configuration discipline and is hard to demonstrate to an auditor.

**Separate cluster with no production credentials and no route to production assets.** Additional footprint; isolation becomes a structural property.

## Decision

The shadow environment runs on a separate cluster holding no production credentials and having no network route to production assets. Its most dangerous possible action is writing a log line.

## Consequences

Additional cluster to operate. Isolation is demonstrable rather than asserted, which matters for accreditation. The traffic duplication queue is explicitly allowed to drop data rather than exert back-pressure on production collection.

## Revisit when

Platform-level isolation guarantees become strong enough to make separate clusters unnecessary.
