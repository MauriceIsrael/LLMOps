## 2. Guiding Architecture Principles

The overarching system design is governed by the platform's non-negotiable architectural principles:
- **`P-001` (Generalized GitOps)**: Network, radio, and platform configurations are declarative, version-controlled in Git, and deployed exclusively through automated CI/CD pipelines.
- **`P-003` (Bounded Unitary Actions)**: Closed automation loops execute idempotent playbooks with a bounded, predictable blast radius. On unexpected failure, execution halts cleanly and escalates without hazardous compensation.
- **`P-004` (Graduated Autonomy)**: Operational autonomy is earned through measured evidence in shadow validation mode, never granted as an unverified default.
- **`P-007` (Respect the Vendor Boundary)**: Orchestration interfaces strictly through vendor-supported northbound APIs (RAN, Core, HSM) without tampering with proprietary software internals.
- **`P-009` (Independent Failure Domain)**: Recovery, backup, and observability chains share zero infrastructure dependencies (compute, storage, transport) with the active systems they manage.
- **`P-010` (One Master per Data Domain)**: Exactly one authoritative master system per data domain (CMDB for physical/virtual inventory, HSS/UDM for subscriber profiles).
- **`P-011` (Separate Observation Planes)**: Hermetic separation between platform infrastructure telemetry and mission-critical application media/signaling flows.
- **`P-015` (The Model Stays Inside the Trust Boundary)**: Sovereign local inference; no prompt, context, or operational metadata leaves the secure project boundary.

## 3. Reference Architecture & Key Patterns

### 3.1 Infrastructure & Resilience Patterns
- **`PAT-003` (Dual-Site Active-Active Geo-Redundant Core)**: Multi-datacenter Tier IV / EN 50600 Class 4 topology delivering transparent automated failover (RTO < 30s, RPO = 0).
- **`PAT-004` (Isolated Local Inference & Secure Gateway)**: Air-gapped isolation enclaves, hardware HSM CC EAL4+ integration, and sub-microsecond IEEE 1588 PTP v2.1 timing with GNSS holdover > 30 days.

### 3.2 Operations & Security Patterns
- **`PAT-001` (Supervised Closed Loops with Human Gate)**: Supervised NOC/SOC automation requiring explicit human gatekeeper sign-off for high-impact actions.
- **`PAT-005` (Immutable Audit & Forensic Logging)**: Tamper-proof Syslog RFC 5424 streaming to a dedicated SIEM bastion with cryptographic WORM sealing.
- **`PAT-006` (Sovereign Interconnection via SEPP / N32)**: Secure roaming and inter-operator interworking compliant with 3GPP TS 33.501.
