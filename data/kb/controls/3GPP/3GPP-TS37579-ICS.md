# 3GPP-TS37579-ICS — Implementation Conformance Statement (ICS) & ETSI MCX Plugtests

## Specification Reference
3GPP TS 37.579 (Mission Critical services conformance testing; Part 1: Common test environment; Part 4: Implementation Conformance Statement - ICS proforma) and ETSI TS 103 564 (Plugtests interoperability events for MCX).

## Technical Requirement
Suppliers of Mission Critical Push-to-Talk (MCPTT), Video (MCVideo), and Data (MCData) servers and client applications must submit a completed 3GPP TS 37.579 ICS proforma and provide evidence of successful interoperability participation and passing test verdicts in the official ETSI MCX Plugtests program and GCF device/client certifications.

## Architecture Acceptance Criteria
- Formal submission of 3GPP TS 37.579 ICS documenting 100% compliance with mandatory profile capabilities.
- Documented proof of inter-vendor session establishment, floor control, and encryption key distribution in ETSI Plugtests.
- Official Global Certification Forum (GCF) certification for production client applications and handheld terminals.
