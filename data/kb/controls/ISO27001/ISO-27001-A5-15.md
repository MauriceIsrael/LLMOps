# ISO-27001-A5-15 — Information Security in Supplier Relationships

## Regulatory Reference
ISO/IEC 27001:2022, Annex A, Control A.5.15 (Information security in the ICT supply chain).

## Standard Requirement
Processes and procedures shall be defined and implemented to manage information security risks associated with the use of third-party products and services.

## Architecture Acceptance Criteria
- Mandatory signed Software Bill of Materials (SBOM) for all third-party and embedded software packages.
- Third-party security posture verification and contractual right-to-audit clauses.
- Mandatory staging in an isolated sandbox environment before production release.
