# ISO-27001-A8-01 — User Endpoint Devices Security and Fleet Management

## Regulatory Reference
ISO/IEC 27001:2022, Annex A, Control A.8.1 (User endpoint devices).

## Standard Requirement
Information stored on, processed by or accessible via user endpoint devices shall be protected.

## Architecture Acceptance Criteria
- Mandatory fleet enrollment through an Enterprise Mobility Management (EMM/MDM) solution.
- Hardware-backed internal storage encryption (FIPS 140-3 or Common Criteria) and disabled insecure physical ports.
- Immediate remote credential revocation and secure wipe capabilities in case of device loss or theft.
