# ISO-27001-A8-09 — Configuration Management and Drift Control (GitOps)

## Regulatory Reference
ISO/IEC 27001:2022, Annex A, Control A.8.9 (Configuration management).

## Standard Requirement
Configurations, including security configurations, of hardware, software, services and networks shall be established, documented, implemented, monitored and reviewed.

## Architecture Acceptance Criteria
- Strict GitOps paradigm where the Git repository serves as the Single Source of Truth.
- Prohibition of manual production adjustments (No-SSH / immutable nodes); changes occur solely via reviewed Pull Requests.
- Automated continuous configuration drift detection with automated reconciliation to intended state.
