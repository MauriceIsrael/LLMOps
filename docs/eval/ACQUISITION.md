# 3GPP Specification Acquisition Manifest

This document specifies the required 3GPP specifications, releases, versions, and official 3GPP portal URLs for the LLMOps 3GPP Elicitation Benchmark Pilot.

---

## Local Acquisition Folder Structure

- Automated or manual PDF uploads must be placed in: `data/eval/sources/upload/3gpp/`
- Text extractions and SHA-256 hash manifests are generated under: `data/eval/extracted/` and `docs/eval/SOURCES.md`.
